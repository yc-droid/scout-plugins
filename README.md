# Scout plugins

Plugins for Claude that connect it to live, official data, by Yash Chowdhury.

| Plugin | What it does |
|---|---|
| [RecallScout](plugins/recallscout) | US safety recalls for cars, child car seats, consumer products and food |
| [DepScout](plugins/depscout) | Vulnerability and malware checks for open-source packages |
| [GrantScout](plugins/grantscout) | US federal grants from Grants.gov |
| [FundScout India](plugins/fundscout) | Indian mutual fund NAVs, returns and SIP calculations |

## Install in Claude Code

```
/plugin marketplace add yc-droid/scout-plugins
/plugin install recallscout@scout-plugins
```

Each plugin is also listed in the Claude directory. All are free and need no account.
